About

Where code almost works.....

The Department of Almost Working Code is a parody school department made by a coder, for coders.

What is this?

A free, silly website full of coding tools, games and jokes: a binary translator, a resume builder, a GitHub guide, a chat with a parody teacher, and many small departments.

It started as a joke inside a coding club and grew into a place to practise real skills while laughing at our own bugs.

Is anyone real here?

No. Every character is made up. The teacher, Sir E, is a parody and not a real AI. Any resemblance to a real person is a bug.

Our kindness promise

  • Roasts are about coding habits only.
  • No looks, family, money, religion, grades or private life.
  • If anything feels unkind, tell the Chief Bug Officer and it will be changed or removed.
